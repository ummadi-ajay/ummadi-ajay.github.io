# MakerWorks Lab website

Source of the [MakerWorks Lab](https://makerworkslab.in/) website, a robotics and Physical AI maker space in Malad East, Mumbai. It is a static site served with GitHub Pages at **makerworkslab.in**.

## What is in here

The site is plain HTML, CSS and JavaScript, organised in folders such as `about`, `blog`, `competetions`, `enrol`, `gallery`, `hiring` and `images`, with the home page in `index.html` and the custom domain in `CNAME`.

Project apps live in their own repositories and are served under the same domain, for example `makerworkslab.in/learn/`: see [learn](https://github.com/ummadi-ajay/learn), [attendance](https://github.com/ummadi-ajay/attendance) and [components-tracker](https://github.com/ummadi-ajay/components-tracker).

## Run it locally

Serve the folder with any static server and open `index.html`.
